# Exact projector, elimination and conditioning supplements

The two Markdown data files supply the exact kernel matrices, elimination
polynomial, Sturm signs, rational four-plane and complementary basis referred
to in the paper. They are mathematical excerpts of the retained evidence,
not claims of physical realization.

The `conditioning` directory contains three certificate data sets and their
separately implemented verifiers. The mathematical algorithms are unchanged.
Public terminology and dependent hash pins were updated on 30 September
2026, and the three reports were regenerated by replay; they are public
adaptations, not the original logs. The hash-pinned `conditioning_fixture.tex`
is a verbatim mathematical excerpt from the original reference draft,
not the current paper and not a standalone LaTeX build. Its private
editorial wrapper was omitted and the two consuming hash pins updated.
No mathematical input or numerical bound was altered by this export.
Use `paper/green_geometry_positive_hermitian.tex` for the full manuscript.

With Python 3.11, SymPy 1.13.1 and NumPy installed, run from the package root:

```
python -B supplements/replay_conditioning.py --out /path/to/new-external-directory
```

The wrapper copies only the certificate subtree to the new directory and
leaves this package unchanged. The three replays must reproduce their stored
reports byte-for-byte. They check the frame-factor bridge, upper bounds,
sampled closed boxes and negative tests. These sampled checks alone do not
prove a complete cover.
Failed attempts are retained; choose a new output directory for another run.

The numbers are certified lower bounds for different explicitly stated
objects, not a comparison of unknown optimal constants or hardware costs.
The five-functional optimality statement uses the cited published theorem;
these computations establish no primitive-shot optimum.

## Complete kernel-floor certificates

The newly retained `complete_projector_cover.json` and
`complete_rational_cover.json` contain every closed and pruned leaf,
not just the one-in-100 samples in the older data. They were regenerated
on 30 September 2026. Stable legacy filenames are retained for cross-references.

Run these read-only full replays from the package root:

```text
python -B supplements/complete_kernel_cover.py --design projector --verify supplements/complete_projector_cover.json
python -B supplements/complete_kernel_cover.py --design rational --verify supplements/complete_rational_cover.json
```

The reference runs took about six minutes and seven seconds respectively.
These are timings, not requirements. `--out` can instead create a new
external certificate. Generation and full replay use the same arithmetic
algorithm; the sampled verifiers provide a separate eigenvalue route only
on their stated samples. See `COMPLETE_COVER_PROOF.md` for the proof logic.

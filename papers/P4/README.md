# Bivariate McKay Recurrences and Meromorphic Tensor-Curl Spectral Functions on Spherical Space Forms

Luqman Mahmood. Manuscript version: 1 October 2026.

Commuting bivariate McKay recurrences organize representation multiplicities and round tensor-curl spectral functions. The paper derives finite Hurwitz-zeta continuation, pole and heat-coefficient structure, moving-offset boundary terms and relative zeta-determinant recurrences. Scope is mathematical and confined to the stated operators and quotients.

Mathematical proof and exact-data scope:

The derivations and displayed exact formulas are in the manuscript. A separate bounded exact regression compares direct symmetric-power weights (and `Q8` character projection) with coefficients generated by the two McKay matrices:

```text
python -B supplement/check_coefficients_offsets.py
```

The three free effective fixtures are `C5` with left/right weights `(1,0)`, mixed `C7` with weights `(1,2)`, and nonabelian `Q8 x C3` with `Q8` in the left slot and `C3` in the right. Both mixed fixtures have two nontrivial projections and distinct rank operators. The checker uses irreducible copy multiplicities, without an extra dimension factor.

It checks the bivariate coefficients for `0 <= p,q <= 12`, rank and diagonal recurrences for `J=1,...,4`, `n=0,...,10`, and the geometric-offset identity for `J=1,...,4`, `s=4,5`, on both branches. The offset check uses exact rational sums with a common physical-energy cutoff `E <= J+13`, preserving the lowest-mode term; omitting that term must fail every tested row. At `J=1`, the lower-rank term is the formal `J=0` seed, not a geometric rank-zero TT operator.

For `J=1,2,3`, it also fits each period-class quadratic from three levels and tests two further periods. The coefficient means in the manuscript's finite-Hurwitz form give the expected branch residues `d_i/|Gamma|`, `0`, and `-J^2 d_i/|Gamma|` at `s=3,2,1` for these fixtures. This is a bounded exact coefficient check, not an independent proof of meromorphic continuation. Nonfree resonances, arbitrary groups, infinite-sum evaluation, heat coefficients, determinants, the historical tables, and the full theorems are not verified by this script.

Python 3.11 standard library suffices for both checks. No private data or source-hash pin is required. The regression prints JSON; optional `--out /path/to/new-result.json` writes a new file in an existing directory outside this paper package and refuses overwrite.
